How to Play Krillion: Rules, Timer and Scoring

This page is the full rules reference for the Krillion Daily Dive: what you type, how long you have, how the six tiers score, and how depth is calculated. It is written for players who want the mechanics straight before their first run.

The 30-second version

  1. Go to krillion.io and open the Daily Dive.
  2. You get seven prompts, the same for everyone that day.
  3. For each prompt, type one valid answer within about 25 seconds.
  4. Valid answers score 10, 15, 30, 60, 85 or 100 points by rarity.
  5. Add the seven scores; multiply by 10 to get your depth in metres.

Step by step

  1. Start the dive. The Daily Dive is the scored daily mode. You do not need an account for the core game.
  2. Read the prompt precisely. Prompts ask for a member of a category — a country, a city, a food, a character, a work, a species. Every word in the prompt narrows the answer set.
  3. Type one answer. The validator checks your spelling against a curated answer set that includes aliases. Autocorrect is deliberately generous, so a one-letter slip can still match.
  4. Submit before the timer. If an entry is not recognised, it scores nothing and the clock keeps running. You get one scored answer per prompt.
  5. Watch the tier reveal. The game shows the accepted answer, its rarity tier and the points you earned, then moves on.
  6. Repeat for all seven prompts. The result screen shows your total depth, which you can share.

The timer

Each prompt gives you roughly 25 seconds. The game previews the next prompt briefly before the answer window opens, so you cannot bank time from one prompt to the next. Miss the window and that prompt is a zero.

Time management matters more than most players expect: reading the prompt carefully for three seconds and typing a clean answer beats rushing a half-remembered name and losing the prompt to a typo.

How rarity is decided

The official FAQ explains that answer sets are built by aggregating sources such as dictionaries, wiki pages and encyclopedias, then merging and cleaning them. Rarity is not one universal formula: some prompts are scored mechanically against a database of how often a word appears in what people read and write; others use a combination of LLM assistance and a manual pass.

Two consequences follow. First, a tier belongs to an answer within a prompt, not to the word forever. Second, the top “One in a Krillion” answer is chosen partly for rarity and partly because it is satisfying to land on — it is a curated gem, not a pure frequency measure.

What counts as a valid answer?

  • It must fit the category as written. A country that starts with S is not any country beginning with “Saint” unless the prompt allows it; read the qualifier.
  • Aliases count. The validator checks alternate names, so “T. rex” and “Tyrannosaurus rex” can both match if the prompt is about dinosaurs.
  • Spelling is forgiving, not infinite. A letter or two off an alias can still match — sometimes producing a funny mismatch. Aim for a clean spelling of a name you know.
  • Blank, invalid or unrecognised entries score zero. There is no partial credit for a miss.

Daily reset and other modes

A new Daily Dive appears each day. Player guides report the reset at 00:00 UTC; the in-game countdown is the authority. Beyond the daily, the official menu links an Unlimited mode, themed packs, an archive and the beta Puffer Party mode. Themed packs are useful for practice because they repeat categories you can study; they do not replace the scored daily.

Five mistakes that cost depth

  1. Typing your first thought. The first answer that comes to mind is usually Plankton. Pause and generate two more candidates.
  2. Chasing “clever” instead of rare. The Too Clever tier exists precisely because the famous obscure pick is still common.
  3. Ignoring a qualifier. “A country in Africa” and “a country that starts with S” have different answer sets; mixing them costs the prompt.
  4. Burning the clock on spelling. If you cannot spell it confidently, pick a slightly more common answer you can type cleanly.
  5. Treating one bad dive as a trend. Seven prompts is a tiny sample; review your misses across several days before changing strategy.

Frequently asked questions

How many prompts are in a Krillion dive?

Seven prompts, the same for every player on that day.

How long do you get per prompt?

About 25 seconds per prompt. The game previews each prompt before the answer window opens.

How many points is a perfect Krillion dive?

700 points: seven answers in the 100-point One in a Krillion tier, equal to 7,000 metres.

Can you retry a prompt in Krillion?

You get one scored answer per prompt. Unrecognised entries score nothing and the timer keeps running; the official client decides whether you can retype before time expires.

Does Krillion require an account?

No for the core Daily Dive. An account is used for purchases and syncing unlocks.

Is Krillion the same as a clone site?

No. The official game is at krillion.io. Several unofficial domains reuse the name; the official FAQ is the authority on rules and scoring.
